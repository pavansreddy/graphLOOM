How to read this

  1. Ontology — each circle is a class (a Neo4j label); size = number of instances. Arrows are relationship types from domain → range. Grey dashed arrows are SUBCLASS_OF; dashed coloured arrows are relations a document declares.
  2. Knowledge graph — each class expands into its entities, coloured by class; hubs grow with connections.
  3. Line styles — solid = explicit (stated in the source) · dashed = inferred (rule or LLM) · dotted = co-occurrence. Filter them with Links shown.
  4. Click anything for properties, provenance and source sentences; double-click a class to explore its instances.
  5. Click legend items to hide classes; Min mentions / Max graph nodes de-clutter big corpora.
  6. Export to Cypher, Excel or Neo4j — in Neo4j, CALL db.schema.visualization() shows the same ontology.
